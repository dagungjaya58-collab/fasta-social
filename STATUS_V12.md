# FASTA v12 — Social Pro

Fitur:
- Sistem pertemanan dan pencarian pengguna.
- Chat realtime dengan foto dan video.
- Feed foto/video dengan like dan komentar.
- Status foto/video yang otomatis kedaluwarsa setelah 24 jam.
- Foto profil dan bio pengguna.
- Indikator online/offline sederhana.
- Daftar percakapan realtime.
- Penyimpanan media menggunakan Firebase Storage.

Catatan:
1. Deploy Firestore rules dan Storage rules terbaru.
2. Jika query status/chat meminta index dari Firebase, buka link index yang diberikan Firebase dan buat index tersebut.
3. Build APK baru dari GitHub Actions setelah file v12 diunggah.
