# FASTA release checklist

- [ ] Firebase Authentication Email/Password enabled
- [ ] Firestore database created
- [ ] Storage enabled
- [ ] Firestore + Storage rules deployed
- [ ] `flutter create . --org com.fasta` completed
- [ ] Android package verified as `com.fasta.social`
- [ ] Google services plugin configured by Flutter/Gradle
- [ ] `google-services.json` present in `android/app/`
- [ ] iOS Bundle ID verified as `com.fasta.social`
- [ ] `GoogleService-Info.plist` present in `ios/Runner/`
- [ ] Android release signing configured for Play Store
- [ ] Apple Developer signing configured for iOS
- [ ] Privacy policy and terms prepared before public launch
- [ ] Test on physical Android/iPhone devices
