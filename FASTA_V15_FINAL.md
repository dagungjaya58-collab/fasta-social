# FASTA V15 FINAL

FASTA V15 adalah paket final gabungan fitur V12-V15.

## Fitur
- Firebase Auth email/password
- Feed foto/video, like, komentar
- Status foto/video 24 jam
- Chat pribadi realtime: teks, foto, video, dokumen
- Friends + friend request
- Followers / Following
- Notifikasi realtime di Firestore
- Group chat + foto/video/dokumen
- Profil profesional: foto, cover, bio, statistik, aktivitas
- Search pengguna
- Online/offline

## Firebase project
Konfigurasi Android yang disertakan tetap memakai project FASTA yang sama dan package `com.fasta.social`.

## Catatan
Video call dan voice note belum dibuat sebagai fitur produksi pada paket ini karena membutuhkan signaling/WebRTC dan recorder dengan konfigurasi native tambahan. Jangan menganggap tombol/fitur tersebut sudah aktif hanya karena nama aplikasi memuat Video.
